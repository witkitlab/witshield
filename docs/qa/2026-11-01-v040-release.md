## 发布规则及重试记录

按维护者的新规则，常规发布在自动检查通过后继续。实际 `release` Environment 的 required reviewers 已移除，Environment 本身、secrets、权限隔离及签名检查保留。CLI 和 Controller 的动作授权、逐项确认没有取消。

原等待审批的作业在环境规则变化后失效，未分配 runner 或执行发布步骤。随后仅重跑失败作业暴露旧 workflow 按 `run_attempt` 猜制品名称的问题，下载失败发生在 GHCR 登录及任何外部发布之前。确认没有部分发布后，对同一不可变标签完整重跑；attempt 3 的预检、发布与五组主机烟测均通过。没有移动版本标签或替换公开资产。

[后续交接修复 #96](https://github.com/witkitlab/witshield/pull/96)改用预检返回的真实 artifact ID，缺失时安全停止；它不追改本次标签源码，跨 attempt 平台级失败任务重试仍需后续版本实测。

`--fix` 仍为实验性功能。云厂商网络拓扑、默认 180 秒完整等待、需改变未授权依赖的整机反例、真实软件包维护脚本的全部恢复副作用尚未由本次验收证明。Gitee 配置及国内链路、可选 DeepSeek 真实调用继续保留为未执行；安全分不能证明主机未被入侵。
