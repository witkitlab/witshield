# AI 提供方

AI 是可选解释与建议层，不是扫描器、动作计划生成器或授权主体。不设置 API 时，确定性规则、Finding、审批和审计仍应工作。

## 支持协议

| 配置值 | 用途 | Base URL 示例 |
|---|---|---|
| `openai_responses` | OpenAI Responses 兼容接口 | `https://api.openai.com/v1` |
| `openai_chat` | OpenAI Chat Completions 兼容接口 | `https://api.example.com/v1` |
| `anthropic_messages` | Anthropic Messages 兼容接口 | `https://api.anthropic.com` |

“兼容”不代表所有第三方实现都完全一致。当前“测试连接”会验证认证、目标模型、一次基础**非流式**请求和响应结构，而不是只请求模型列表；当前 AI 客户端不使用流式输出，因此测试也不承诺验证第三方 SSE/流式兼容性。

## 自定义 URL 的安全含义

配置 Base URL 表示管理员明确允许巡御把选中的安全上下文发送给该上游。设置前确认：

- 服务运营者、数据位置和保留政策；
- TLS 证书链和域名是否可信；
- 是否会记录请求头、提示词或响应；
- TLS 证书是否已被运行环境的系统信任库验证；
- 是否经过会修改流式、JSON schema 或错误格式的 API 网关。

API Key 与敏感自定义请求头绑定到 endpoint origin（scheme、host、有效端口）。同一 origin 内可以调整路径、协议适配或模型并保留 Key；更换 origin 时必须重新输入或明确清除，连接测试也不会把旧 Key 自动发送到新地址。

巡御不提供“忽略 TLS 错误”，当前版本也没有单独上传自定义 CA 的入口。内网上游应放在受信 TLS 网关之后；如必须把私有 CA 加入宿主机系统信任库，应先评估它对整台主机的信任面影响。Docker 观察镜像需要重新构建并固定 digest，不能临时把未知 CA 或关闭校验参数注入运行容器。

## 数据最小化

向模型发送前应优先转换为：规则 ID、严重性、受影响组件、必要的版本/配置证据和脱敏上下文。默认不发送：

- 私钥、密码、API Key、Cookie、完整环境变量；
- 与 Finding 无关的文件正文或日志批量原文；
- `/etc/shadow`、云元数据凭据、SSH 私钥；
- Controller 主密钥、注册令牌、设备身份密钥；
- 用户未选择的历史报告。

服务器上的文本可能包含提示注入。模型请求会把它标为不可信数据；无论模型如何回答，后续仍需动作 schema、策略和审批验证。

## Key 生命周期

- 通过认证后的设置页面/API 写入；
- 使用 Controller 主密钥加密后落盘；
- 读取 API 不返回明文；
- 同一 endpoint origin 内更新设置时省略 `apiKey` 表示保留；
- 只有显式 `clearApiKey: true` 才清除；
- 日志、错误和诊断导出必须经过静态脱敏；
- 轮换后执行一次连接与最小请求测试。

如果上游 Key 泄露，请先在上游吊销，然后在巡御中写入新 Key；仅在 UI 中清除旧 Key 不能撤销上游权限。

## 超时与降级

当前实现限制连接建立与整体请求时间，并把响应正文限制在 2 MiB；连接测试另有 20 秒上下文期限。网络错误、429、5xx、无效 JSON 或结构不匹配时：

- 不自动重试可能产生副作用的动作；
- 当前请求直接向 UI 返回脱敏错误，不假定上游重试安全；
- Finding 保留规则生成的内容；
- 明确显示“AI 不可用”，不伪装成零风险；
- 绝不退化为执行模型原始文本或 shell。

## 额外请求头

`customHeaders` 可支持企业网关的版本或路由头。禁止覆盖安全关键头（例如 `Host`、`Content-Length`、连接控制），也不要在值中写入可由扫描内容控制的模板。含授权信息的自定义头按秘密处理。
